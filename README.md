# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №3.

## Что реализовано

### Flexbox
- **Навигационное меню** - горизонтальное на десктопе, вертикальное на мобильном.
- **Карточки релизов** - 4 в ряд на десктопе, 2 на планшете, 1 на мобильном.
- **Форма обратной связи** - вертикальный flex-контейнер.

### CSS Grid
- **Дашборд «Студийное оборудование»** - 3 колонки * 2 строки на десктопе, 2 колонки на планшете, 1 на мобильном.
- **Карточки оборудования** через `<figure>` + `<figcaption>`.

### Семантика и доступность
- Использованы теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
- Карточки релизов - `<article>`, оборудование - `<figure>`.
- Год релиза обёрнут в `<time datetime="ГГГГ">`.
- Видимый фокус для полей ввода и кнопки (`:focus`).

### Адаптивность
- **Медиа-запросы:** десктоп (`min-width: 993px`), планшет (`max-width: 992px`), мобильный (`max-width: 576px`).
- **Защита от горизонтальной прокрутки:** `box-sizing: border-box`, `overflow-x: hidden`, `img { max-width: 100%; }`.
- **Адаптивные изображения:** `aspect-ratio` + `object-fit: cover` вместо фиксированной высоты.
