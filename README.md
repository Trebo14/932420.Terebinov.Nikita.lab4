# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №4.

## Что реализовано
- Подключён внешний файл `script.js`.
- Реализован ввод имени через `prompt` с обработкой отмены и пустой строки.
- Вывод приветствия через `alert` и лог в консоль.
- Создан массив `trackVolumes` из 7 значений.
- Реализован цикл для поиска и подсчета тихих треков.
- Написаны функции:
  - `findMaxVolume` - поиск максимального значения в массиве.
  - `filterLoudTracks` - фильтрация громких треков (громкость > 90 дБ).
  - `calculateSum` - вычисление суммы элементов массива.
  - `analyzeQuietTracks` - инкапсулированная логика анализа тихих треков.
- Вывод средней громкости и количества громких треков через `alert`.
- Вывод количества тихих треков и их средней громкости в `console`.
- Реализована дополнительная проверка: если максимальная громкость >= 105 дБ, то в консоль выводится предупреждение о вреде для слуха.
